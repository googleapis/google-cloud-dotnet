The Rapid Migration Assessment API is officially deprecated.

The Google.Cloud.RapidMigrationAssessment.V1 package is delisted from NuGet,
and the source code removed from the google-cloud-dotnet repository.
Any projects that depend on the package will still be
able to restore that dependency, but the package won't be shown in
search results on [nuget.org](https://www.nuget.org/).

For more information, see the [Rapid Migration Assessment deprecation documentation](https://docs.cloud.google.com/migration-center/docs/deprecations).
