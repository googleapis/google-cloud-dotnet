The Area 120 Tables API is officially deprecated.

The Google.Area120.Tables.V1Alpha1 package is delisted from NuGet,
and the source code removed from the google-cloud-dotnet repository.
Any projects that depend on the package will still be
able to restore that dependency, but the package won't be shown in
search results on [nuget.org](https://www.nuget.org/).

For more information, see the [Area 120 Tables deprecation documentation](https://support.google.com/area120-tables/answer/10831919).
